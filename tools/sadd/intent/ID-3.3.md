## Design Intent
Register every AI agent as its own identity, scoped to the data and tools its approved use case needs. No agent identity can reach a tool that tasks an aircraft or changes a system without a named human role approving the action first. The mission-planning agent is the first, scoped to reading mission data and drafting plans, so an operator's approval stays the only path from a draft to a flight.

## External Dependencies
None outside the boundary.
