## Design Intent
Register every AI agent as its own identity, scoped to the data and tools its approved use case needs. No agent identity can reach a tool that tasks an aircraft or changes a system without a named human role approving the action first. The mission-planning agent and the coding agent are the first two. Neither calls a tool server outside the boundary. Each acts for the requesting user, and its sessions end at a fixed limit. Each agent's scope is reviewed for the combination of untrusted input, sensitive data, and the ability to send data out or change state. The mission-planning agent holds all three, since the reports it reads come from collection an adversary can shape. The AO accepts that combination because the agent writes only drafts and an operator approves each one. A deterministic check also holds each plan to approved areas and airspace. The coding agent also holds all three, since it reads third-party code and issue text, holds source code, and pushes changes. The AO accepts it because its sandbox has no path to the internet and holds no credential. Nothing it pushes runs with a pipeline identity or merges before a person reviews it. Delegated scope narrows at each hop, and no credential enters the model's context.

## External Dependencies
None outside the boundary.
