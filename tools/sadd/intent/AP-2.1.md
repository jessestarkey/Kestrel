## Design Intent
The performer agreement requires security plugins in the development environments its developers use for KESTREL work. The plugins flag vulnerable patterns and secrets as code is written, and they never send KESTREL code outside the boundary. Developers who want AI help use KESTREL's own coding agent, reached only from the developer VDI pool. Each session runs in its own sandbox. A policy check outside the agent rules on every command and file action, and denies any it cannot decide. The sandbox reaches only cached approved packages, so it has no path to the internet, and it holds no credential. A broker outside the sandbox clones and pushes for the developer with a short-lived token, and makes every model call. It pushes only to unprotected branches. Pipelines on those branches run without the team's pipeline identity until a reviewer approves the change. A repository's agent instructions and setup scripts take effect only after the developer approves them, and destructive git operations are blocked. Its notebook kernel, browsing helper, and saved conversations are disabled. The plugins aid the developer, while the pipeline's scans remain the authoritative check.

## External Dependencies
The performer, which under the interconnection agreement equips the laptops its developers use for KESTREL work.
