## Design Intent
Each fielded model and use case is re-tested against current jailbreak, injection, and evasion techniques each quarter, and the mission-planning agent each month. It is also re-tested when the provider retires a pinned foundation model version, or when an agent's tools, memory, or input trust change. Results go to the PMO ISSE, and a failure reopens certification.

## External Dependencies
The IL5 cloud provider, which hosts each foundation model deployment inside KESTREL's tenant under its provisional authorization.
