## Design Intent
Each interconnection in the system description has a signed agreement that documents both sides' interfaces and controls. These cover the cloud provider, the Boundary Cloud Access Point, the CSSP, the cross domain service provider, each partner nation, the performer, the penetration testing provider, and the alternate site's facility. Each agreement is reviewed each year and whenever its connection changes.

## External Dependencies
Every interconnected party listed in the system description, as a signatory to its agreement.
