## Design Intent
Fleet Operations adopts each manufacturer's hardening guidance for the ground control stations, launch and recovery equipment, and aircraft. An asset that cannot be hardened to a current baseline gets a compensating control baseline instead. The payload processing workstation would get one only if it connects before its replacement fields. It would then run isolated in the OT zone with application allow-listing, per CCSD tailoring action 3. Approved firmware for each aircraft and station model is tracked in the inventory.

## External Dependencies
The aircraft and ground equipment manufacturers, for hardening guidance and approved firmware. Payload Vendor A, which certifies its conversion software only on the workstation's current operating system.
