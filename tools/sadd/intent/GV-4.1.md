## Design Intent
The AI use case inventory lists every AI use case KESTREL runs or has proposed, with its sponsor, models, data, any actions it can take, and its risk tier. Today the use cases are onboard and cloud detection, imagery sanitizing, the LLM analyst assistant with its report search, the mission-planning agent, AI-assisted alert triage, and the coding agent. Each entry names the model versions it runs on, so a change to one model resolves to every use case it affects. The risk tier rises with mission impact and with any ability to act. Each quarter a discovery sweep checks procurement records, cloud AI service usage, and AI features vendors have switched on in owned products, against the model registry.

## External Dependencies
None outside the boundary.
