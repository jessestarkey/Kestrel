## Design Intent
The cloud provider's threat detection runs on every cloud database and storage service. Access analytics in the security monitoring platform cover the data lake zones on premises and the report index's logs. Alerts cover unusual reads, bulk exports, and access from an unexpected spoke. The CSSP triages each one, the zone's intelligence mission lead joins the investigation, and the IRP sets when it becomes an incident.

## External Dependencies
The IL5 cloud provider, which supplies the database threat detection service under its provisional authorization. The CSSP, which triages these alerts around the clock.
