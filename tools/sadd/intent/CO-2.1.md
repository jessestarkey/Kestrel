## Design Intent
The ISSM authors KESTREL's continuous monitoring plan, and the program manager reviews it as system owner. It names the metrics monitored, how often each is collected, how often each control is assessed, and who receives the results. The AO approves it, and it is revised each year and with every significant change. It also watches for a slip of the replacement payload processing workstation past 2027-09-30, which needs the AO to re-date CCSD tailoring action 3, and tracks action 6's annual review. Security status goes to the AO each month in summary and each quarter in full.

## External Dependencies
None outside the boundary.
