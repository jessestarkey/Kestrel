## Design Intent
Treat the identity provider as the asset whose loss hands an adversary every boundary, and watch it accordingly. Identity threat detection feeds the security monitoring platform. The directory is hardened to its DISA STIG, and its cloud copy to the cloud provider's security baseline for the IL5 identity service.

## External Dependencies
KESTREL's Microsoft 365 DoD tenant, which supplies identity threat detection under its IL5 authorization.
