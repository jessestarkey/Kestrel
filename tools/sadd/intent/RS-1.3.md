## Design Intent
The response team runs a tabletop twice a year, one with an aircraft or ground segment scenario and one with an AI scenario. It also runs a functional exercise each year with the CSSP and the contingency plan's owners, using the real tools in a representative environment. Fleet systems join only by simulator or discussion. Each exercise's findings become tracked changes to the IRP and runbooks.

## External Dependencies
The CSSP, which takes part in the functional exercise.
