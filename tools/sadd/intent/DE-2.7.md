## Design Intent
Flow logs from every spoke, the SDN fabric's flow telemetry, and every firewall's allow, deny, and rule-change events go to the security monitoring platform. That includes the alternate site firewall and each ground segment firewall. Every resolver's query logs, from the cloud to each operating site, go there too. They are stitched into one view of each connection across the circuits.

## External Dependencies
None outside the boundary.
