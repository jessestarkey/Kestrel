## Design Intent
Every AI use case and every new model enters through the application intake path with an AI section added. It names the sponsor, the data the use case needs, any action it can take, and a proposed risk tier. The sponsor is the intelligence mission lead for a mission use case and the ISSM for a security use case such as AI-assisted alert triage. The AI/ML Governance Review Board (`GV-4.4`) approves the use case, with any conditions, before any corpus is assembled.

## External Dependencies
None outside the boundary.
