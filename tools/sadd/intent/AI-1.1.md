## Design Intent
Every AI use case and every new model enters through the application intake path with an AI section added. It names the sponsor, the data the use case needs, any action it can take, and a proposed risk tier. The sponsor is the intelligence mission lead for a mission use case and the ISSM for a security use case such as AI-assisted alert triage. The engineering lead sponsors a development use case such as the coding agent. A model adopted before any use case enters as a platform model with a sponsor and a deadline for its first use case. It is reached only from ML Dev/Test, with no ML Prod deployment, until a use case is certified on it. The AI/ML Governance Review Board (`GV-4.4`) approves the use case, with any conditions, before any corpus is assembled.

## External Dependencies
None outside the boundary.
