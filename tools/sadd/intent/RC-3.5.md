## Design Intent
The fleet keeps flying without the cloud or the data center. Operators fly from the ground control stations with local smart card sign-in. Aircraft keep recordings on their storage modules until the lake returns, which bounds how long the fleet can fly without it. If the data center is lost, analysts work from the last delivered products, and mission planning reverts to manual if the planning agent is unavailable. The program manager authorizes entering and ending fallback. Every contingency role, from operators to restore operators and Tier 0, trains within a set period of assignment, on system change, and each year.

## External Dependencies
None outside the boundary.
