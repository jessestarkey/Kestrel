## Design Intent
The program manager owns the business impact analysis, which covers every mission process, today flying and controlling the aircraft, collecting and ingesting data, detecting and analyzing, releasing to partners, and retraining models. The intelligence mission leads and Fleet Operations' operations lead set how long each can be lost and map each to its CCSD rows. The analysis traces each process to identity, the PKI, the hubs and circuits, and the security monitoring platform. Results are recorded as inventory tags that set the recovery tiers and incident severity. It is reviewed each year and after any significant change.

## External Dependencies
None outside the boundary.
