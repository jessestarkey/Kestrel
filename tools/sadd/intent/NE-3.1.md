## Design Intent
Cloud flow logs, the SDN fabric's flow telemetry, both hubs' logs, and the ground segment sensors all report to the security monitoring platform. Its network posture dashboard shows segmentation coverage, hub rule health, and DDoS and WAF alerts. The Platform Team, the Security Team, and the CSSP all read the same dashboard.

## External Dependencies
The CSSP, which receives the same network telemetry by forwarding.
