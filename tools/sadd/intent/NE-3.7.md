## Design Intent
The Security Team scans KESTREL's public addresses and names each month from outside, and it compares what it finds with the inventory. KESTREL's source code is held on performer laptops, so the Security Team also watches public code hosting and paste sites for its code, secrets, and credentials. Each finding opens a service desk ticket to the owning team.

## External Dependencies
The CSSP, which reports external exposures and leaked credentials it sees in its threat intelligence.
