## Design Intent
The Security Team watches KESTREL's public names and addresses continuously from outside, and it reviews what it finds against the inventory each month. KESTREL's source code is held on performer laptops, so the Security Team also watches public code hosting and paste sites for its code, secrets, and credentials. Each finding opens a service desk ticket to the owning team.

## External Dependencies
The CSSP, which reports external exposures and leaked credentials it sees in its threat intelligence.
