## Design Intent
A breach and attack simulation platform runs known techniques against the cloud spokes, the data center, and identity each month, and confirms which ones the security monitoring platform caught. The Security Team and the CSSP run a purple team exercise each quarter. Once a year, an unannounced campaign emulates a named actor from the threat model under rules of engagement agreed with each owning team. A missed technique closes only when it is re-run and the detection fires. Fleet systems are emulated only on spares or the simulator.

## External Dependencies
The CSSP, which joins each purple team exercise. The penetration testing provider, which runs the annual campaign.
