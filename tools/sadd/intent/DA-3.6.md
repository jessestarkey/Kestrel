## Design Intent
Key administrators, key users, and key auditors are separate roles. Tier 0 administrators manage keys, workload identities and Fleet Operations' key loading staff use them, and the Security Team audits them. No identity holds two of these roles. Changing a key service's access policy needs a second Tier 0 approver and alerts the Security Team, and key operations by any other identity alert too.

## External Dependencies
None outside the boundary.
