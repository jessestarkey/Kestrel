## Design Intent
KESTREL has no classified endpoints, so CNSSD 504's user activity monitoring mandate does not apply. KESTREL still records every privileged session on the privileged access workstations and in the VDI host pools. The Security Team reviews those recordings when an alert fires, and on a sample each month. Indicators go to the PSO's insider threat program.

## External Dependencies
The PSO's insider threat program, which receives referrals and owns every case.
