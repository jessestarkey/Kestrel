## Design Intent
KESTREL's data leaves only by named paths, so DLP watches each one. The partner API and the cross domain transfer gateway check every release against its markings and block anything not releasable. Pushes to the source repository are scanned for mission data and secrets before they reach a branch performer laptops can clone. The workspaces and VDI desktops block downloads and clipboard. Telemetry to the CSSP (F11) leaves under the service agreement's feed terms. Analytics flag bulk reads across zones, and the data security dashboard serves the Security Team, the PMO ISSE, and the data owners.

## External Dependencies
None outside the boundary.
