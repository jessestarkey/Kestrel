## Design Intent
KESTREL's data leaves only by named paths, so DLP watches each one. The partner-facing APIs and the cross domain transfer gateway check every release against its markings, and anything not releasable is blocked. The experimentation workspaces and VDI desktops block downloads and clipboard. Insider risk analytics flag bulk reads across zones, and the data security dashboard shows all of it to the Security Team.

## External Dependencies
None outside the boundary.
