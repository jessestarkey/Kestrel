## Design Intent
Each foundation model is a CSP-hosted deployment inside KESTREL's boundary, reached by private endpoint. Calls authenticate with workload identity, and key-based authentication is disabled, so no API key exists. Processing stays in United States regions within the provider's IL5 authorization, the SA-9(5) parameter CCSD tailoring action 5 sets. The ISSM reviews the provider's continuous monitoring deliverables and confirms each year that prompt logging stays off. Each deployment pins its version, and a retirement notice triggers re-testing before the use case moves.

## External Dependencies
The IL5 cloud provider, which hosts each foundation model deployment inside KESTREL's tenant under its provisional authorization. The model's publisher, whose versions and deprecations the provider passes on.
