## Design Intent
The Security Team gets read access to the asset inventory, discovery results, and tags, and no right to change them. Inventory and tag data flow into the security monitoring platform, so every alert there carries its asset's owner, team, and criticality. The CSSP's analysts see that context only through the platform's enrichment, in their host pool. The same data feeds vulnerability prioritization and incident response.

## External Dependencies
None outside the boundary.
