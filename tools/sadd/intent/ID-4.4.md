## Design Intent
Vault the built-in administrative accounts on the HSMs, network appliances, hypervisors, out-of-band controllers, database engines, and the ground segment's local administrators. Broker and record every session that uses one, and let reviewers watch it live and end it. Two people are required for HSM key ceremonies, fleet counter-signing, root CA operations, deleting audit records, and changing a cloud tenant's security settings.

## External Dependencies
None outside the boundary.
