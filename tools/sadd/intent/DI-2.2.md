## Design Intent
A merged pull request is the change record for anything defined as code, and the service desk holds the record for everything else. Each change is tested in the owning team's stage cluster before it reaches production. Changes to the hubs' shared rule base, the identity provider, or a new interconnection go to the Configuration Control Board. Emergency changes run through the privileged access platform and receive a retrospective review within two business days.

## External Dependencies
None outside the boundary.
