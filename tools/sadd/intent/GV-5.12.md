## Design Intent
Before KESTREL inherits any control, the ISSM confirms the provider's authorization or certification is current. The providers are the cloud provider and the Microsoft 365 DoD tenant, each authorized at IL5. They also include the Boundary Cloud Access Point, DoD PKI, the CSSP's certification, the cross domain service provider, and the alternate site's facility. Each provider's customer responsibility matrix is merged into the SCTM. Provider status is checked each quarter, and the reciprocity terms are recorded with each agreement.

## External Dependencies
The IL5 cloud provider and DISA, which publishes its provisional authorization. Microsoft, for KESTREL's Microsoft 365 DoD tenant. The Boundary Cloud Access Point, DoD PKI, the CSSP, the cross domain service provider, and the parent organization's facility, for the controls KESTREL inherits from each.
