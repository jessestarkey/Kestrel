## Design Intent
Before KESTREL inherits any control, the ISSM confirms the provider's authorization is current. The providers are the cloud provider's IL5 provisional authorization, the Boundary Cloud Access Point, the CSSP, the cross domain service provider, and the alternate site's facility. Each provider's customer responsibility matrix is merged into the SCTM. Provider authorization status is checked each quarter, and the reciprocity terms are recorded with each agreement.

## External Dependencies
The IL5 cloud provider and DISA, which publishes its provisional authorization. The Boundary Cloud Access Point, the CSSP, the cross domain service provider, and the parent organization's facility, for the controls KESTREL inherits from each.
