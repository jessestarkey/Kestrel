## Design Intent
Cloud configuration checks watch every platform service against its baseline. The check with the highest priority is a re-enabled public endpoint on any foundation model deployment. Provider-side prompt logging is confirmed off each year where these checks cannot read it. The same checks cover how each application is hosted, and findings appear on the platform and application compliance dashboard.

## External Dependencies
The IL5 cloud provider, whose controls KESTREL inherits under its provisional authorization. The provider exposes the configuration state these checks read.
