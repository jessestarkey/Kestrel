Each AI agent will have an identity of its own, an Entra workload identity on AKS in the spoke that runs it. That identity reaches only the tools its use case approves. The first two agents arrive in Phase 3. The mission-planning agent drafts flight plans, and the coding agent opens merge requests. Each acts for the user who started its session, each session ends at a fixed limit, and neither calls a tool server outside the boundary.

Both agents combine untrusted input, sensitive data, and the ability to change something. Because that combination makes an agent high risk, the AO accepts each agent's scope before it acts, on the strength of a different safeguard for each. The planning agent writes only drafts, an operator approves every one, and a deterministic check holds each plan to approved areas and airspace. The coding agent works in a sandbox with no path to the internet and no credential, and nothing it pushes merges until a person has reviewed it. Each tool approval expires after a year and has to be renewed.
