Access will be granted through role bundles. Each user role in the system description gets an entitlement bundle, scoped to the team that role belongs to. An analyst's bundle, for example, reaches their own mission team's raw collection and detections, plus the shared reports every team can read. Approving an AI agent's work is part of a bundle too. Operators approve the mission-planning agent's drafts, and developers' reviewers approve the coding agent's merge requests.

Every change goes through a recorded request. Active Directory groups own membership for each role, and IT Operations changes them only through Jira Service Management. The approval itself comes from the requester's product owner or team lead, which keeps anyone from both approving and provisioning the same access. Entra ID Governance access packages fill the gap for the few resources that exist only in the cloud.
