Administrative access gives an attacker the most leverage, so KESTREL will restrict it more tightly than any other access. No account will hold a standing privilege. Instead, an administrator activates a role for a bounded window, and the session that uses it is brokered and recorded. Tier 0, which covers the directory, the PKI, and the HSMs, has an added restriction. It can be administered only from physical workstations in the data center and at the alternate site.
