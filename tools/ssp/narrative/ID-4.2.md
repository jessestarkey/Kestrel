Administrative access will also depend on the device it comes from. Tier 0 and the cloud tenant-owner roles will be administered only from physical privileged access workstations in the data center and at the alternate site. These run Windows 11 Enterprise, hardened to the DISA STIG. Other Tier 1 work runs from the Platform Team's Azure Virtual Desktop host pool.

That host pool is reached from performer laptops KESTREL does not own, which is a known weakness. The broker is built to compensate for it. It checks the CAC and the laptop's posture, allows elevation only inside the session, records everything, and lets a reviewer end a session live. Smart card redirection is allowed, while clipboard, drive, and USB redirection are blocked. Anyone who works across tiers also holds a separate account for each one.
