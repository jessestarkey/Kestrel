KESTREL will keep break-glass accounts for the case where normal sign-in fails. There will be break-glass accounts for the cloud tenant, the directory, and the ground segment. The two cloud accounts use different phishing-resistant methods, one a YubiKey and the other a certificate from a dedicated break-glass CA, so a single failure cannot take out both. The directory set covers a domain account, each domain controller's DSRM password, and a local administrator on each privileged access workstation. Every station has its own local account as well.

The directory and station accounts are console-only passwords under CCSD tailoring action 6, which still awaits the AO's decision. If the AO declines it, offline smart cards in the same seals take their place. Using any of these accounts alerts the Security Team and the CSSP at once, and each password is changed after use. Sessions are short, too. A directory session ends after four hours, and a station session ends once no aircraft under that station is airborne. The cloud and directory sets will be sealed at the data center and the alternate site from Phase 1. The station accounts follow at each operating site from Phase 3.
