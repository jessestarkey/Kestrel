From Phase 2, KESTREL's own services will authenticate to each other with mutual TLS, using program PKI certificates. That includes traffic across the circuits and into the feedback endpoints that accept IL6 products, where an unauthenticated caller would be most dangerous. Inside the clusters, the Istio service mesh issues the workload certificates from an intermediate under the program PKI. Data center services get theirs from Keyfactor Command.

Each internal service trusts only the program's own issuing authorities. The partner API is the one place that trusts more, since it also accepts the partner and ECA issuers on the external trust list. Elsewhere, provider-managed services authenticate callers by workload identity. User-facing edge services, for their part, present DoD PKI server certificates that browsers and partner systems already trust.
