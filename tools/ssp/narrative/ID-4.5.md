Maintenance on the fleet will happen only in scheduled windows, starting in Phase 3. Each operating site will have a weekly window, opened against an approved change record, and covering the ground control stations, launch equipment, and aircraft. The one firm rule is that no window opens while an aircraft under its stations is airborne. Extending a window needs both Fleet Operations' operations lead and an ISSO.

Tools are inspected before they are used. Model packages also load only during these windows, which ties maintenance to the path that carries new edge models to the aircraft.
