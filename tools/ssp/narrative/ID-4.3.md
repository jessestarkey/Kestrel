No privilege in KESTREL will be standing. Every cloud, data center, and ground segment privilege is instead eligible, and an administrator activates it only for a bounded window. Cloud roles are activated through Entra Privileged Identity Management, while on-premises and fleet roles go through CyberArk. The PKI and HSMs carry extra weight, so activating access to them needs a second approver.

For Tier 1, elevation happens inside an administrative VDI session. The credentials and tokens it produces therefore stay in that session and never reach the performer's laptop.
