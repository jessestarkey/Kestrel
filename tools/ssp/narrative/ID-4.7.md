Vendor access will run through a single controlled path. A vendor engineer connects from a dedicated host pool in Azure Virtual Desktop, using an ECA Medium Hardware credential. Even then, the session must be for an open Jira Service Management case that the system-owning team lead sponsors. CyberArk brokers and records every session. No session lasts longer than eight hours, and each one ends when its case closes.

Fleet vendors face one more limit, which is the maintenance window. Within it, they either work on site under escort or connect through the same brokered path.
