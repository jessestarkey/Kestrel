# Control Narratives

Each file here holds the implementation narratives for one NIST control family, such as `IA.md`, with one `## <control ID>` heading per control. The SCTM build puts each narrative in its control's row and adds the provider's part, any CCSD tailoring, and a link to the SSP.

Write for an AO or assessor who has never seen the SABER. Say what the control requires of KESTREL and how KESTREL meets it, naming the products and where they run. Leave out SABER terms such as outcome IDs, activity names, and which outcome holds which part of a control, since the link to the SSP carries that trace.

Use the future tense for planned work, and rewrite in the present tense once it is built, as the SSP's narratives do. Keep the house style: plain descriptive sentences, no em dashes, no semicolons, and bare control IDs.

A control with no narrative shows that one is not yet written.
